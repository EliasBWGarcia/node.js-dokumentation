Datatyper

I JavaScript (og i andre sprog) findes der forskellige datatyper, som fortæller om hvilken slags værdi en variabel indeholder. For eksempel kan integers bruges til matematiske beregninger, mens strings bruges til tekst. Nedenfor har jeg lavet en liste, der beskriver nogle de forskellige datatyper og en tilhørende beskrivelse:

String
En string er en tekst, der skrives i citationstegn.
Number eller integer
Et number eller integer er tal, der kan bruges til beregninger.
Boolean
En boolean er enten true eller false. Dette bliver fx. brugt i et if statement
Undefined
Undefined btyder, at der ikke er nogen værdi at arbejde med. Det kan ske, hvis en varibel er oprettet uden at få assignet en værdi endnu, eller hvis man prøver at hente noget fra et objekt, som ikke findes. eksempel: 
const username; 
console.log(username) // undefined

const user = {name: "Elias"}
console.log(user.age) // undefined
Null
Dette er hvis man bevidst sætter værdien til at være tom.
Objekt
Dette er en samling af key value pairs. Det kan bruges til at beskrive personer eller andre ting med flere oplysninger, hvor man henter ting fra objektet med dot notation. Klik på titlen for at se mere om objekter
Array
Dette er en liste med flere værdier. Det kan for eksempel være en liste med frugter, hvor hvert element har et index, som altid starter ved 0. Et array kan også indeholde objekter. Klik på titlen for at se mere om arrays

Dato og tid

JavaScript har et indbygget date objekt. Dates bliver gemt som integers i form af millisekunder siden 1. januar 1970, og det gør det muligt at beregne tid og dato.

Eksempel med beregning af datoer

const tomorrow = new Date(Date.now() + 1000 * 60 * 60 * 24)

Her opretter new Date() et date objekt ud fra det aktuelle tidspunkt. Derefter lægges antallet af millisekunder i et døgn til, så resultatet bliver datoen i morgen.

Eksempel med formatering af datoer

const currentMonth = new Date().toLocaleDateString('en-uk', { month: 'long' });

new Date() opretter et date objekt ligesom i forrige eksempel. toLocaleDateString() formaterer datoen som tekst og month: "long" gør at resultatet bliver navnet på den aktuelle måned, man er i.

Variablerne const og let

Variable bruges til at gemme værdier, og i Javascript bruges const og let.

Const

Const bruges, når værdien ikke skal laves om senere i programmet igen. Derfor bruger man som udgangspunkt altid const for at undgå bugs. 

const name = "Elias"

Let

Let bruges når en værdi ændres senere i programmet. fx: 

let score = 0 
score = score + 1

Objekter

Som tidligere nævnt samler et objekt oplysninger om fx. en person i key value pairs. Det giver mening, når flere værdier hører sammen under samme "kategori". Eksempel: 

const person = {
            id= 1,
            name: "Elias"
            age: 25
        }

i ovenstående eksempel er id, name og age keys, og deres tilhørende values er henholdvis 1, "Elias" og 25.

Hvordan henter man et bestemt property fra et objekt?

console.log(person.age) // output: 25

Man bruger dot notation for at hente et bestemt property fra et objekt.

Ændring af properties i et objekt

Man kan også tilføje eller ændre properties på et allerede eksisterende objekt. 

person.age = 30;
person.name = "Jacob"
person.hobby = "Playing guitar"

Her ændres værdien af age og name, og der tilføjes også en ny property, som hedder hobby. Selvom objektet er oprettet med const, kan man godt ændre objektets properties, dog kan man ikke reassigne et nyt helt nyt objekt til person

Arrays

Et array bruges til at gemme flere værdier i samme variabel. alle værdier i arrayet har et index, og det første index er altid index 0. 

const instruments = ["Guitar", "Piano", "Drums"];

Hvordan tilgår man værdier i et array?

console.log(instruments[0]); // "Guitar"
console.log(instruments[1]); // "Piano"

Square brackets bruges til at hente en værdi ud fra dens index. Det er derfor instruments[0] henter den første værdi i arrayet.

Antal værdier i et array

console.log(instruments.length); // 3

Length fortæller, hvor mange elementer eller værdier der findes i arrayet.

Et array kan også bestå af objekter

Som tidligere beskrevet, kan et array bruges til at gemme flere værdier i en variabel. Et array kan også indeholde flere objekter, som på nedenstående eksempel:. 

const guitarCollection = [
        {id: 1, instrument: "Guitar", type: "Acoustic"},
        {id: 2, instrument: "Guitar", type: "Electric"}
        ]

Herfra kan man hente en bestemt property fra et objekt på arrayet:

console.log(guitarCollection[0].type) // "Acoustic"
console.log(guitarCollection[1].type) // "Electric"

Funktioner

En funktion er en blok kode, der kan genbruges flere steder. Det er et stykke kode, der helst kun skal stå for at udføre 1 opgave. Funktioner kan modtage værdier som parametre og kan returnere et resultat, som evt. kan blive brugt et andet sted i koden.

Hvordan skriver man en funktion?

function getGreeting(name) {
            return "hej " + name
        }
const greeting = getGreeting("Elias")
console.log(greeting) // output: "Hej Elias"

Funktionen modtager name som et parameter og returnerer en string. Når funktionen kaldes, bliver argumentet "Elias" brugt som name.

Arrow function

const getGreeting = (name) => {
            return "Hej " + name
        }

En arrow function er en anden måde at skrive en funktion på, hvor denne fx. kan logges ved at skrive:

console.log(getGreeting("Elias")) // output: "Hej Elias"

Man kan også gemme resultatet i en variabel som her:

const greeting = getGreeting("Elias")
        console.log(greeting) // output: "Hej Elias"

Callback functions

En callback funktion er når en funktion tager en anden funktion som parameter som i nedenstående eksempel:

function performAction(name, action) {
            return action(name)
        }
const playGuitar = (name) => {
    return name + "like to play guitar"
}
console.log(performAction("Elias", playGuitar))

Her bliver der lagt to argumenter ind til funktionen performAction, hvor playGuitar er sendt ind som callback og bliver kaldt inde i performAction med argumentet "Elias"

Scope

Scope fortæller om, hvor i koden en variabel er tilgængelig. Der er 3 primære måder at definere scopes på:

Global scope

let score = 0
for (let i = 0; i < 10; i++) {
    score = score + 1
}

Variablen score i ovenstående eksempel er oprettet uden for loopet og kan derfor tilgås i hele programmet, både inde i loopet og efter loopet, fordi den har global scope. altså, variablen er oprettet uden for nogen funktion og er derfor tilgængelig i hele programmet.

Function scope

function convertNoteToHZ(note) {
        const notes = {
            A4: 440,
            C4: 261
        } 
        return notes[note]
    }

i ovenstående eksempel er notes oprettet inde i funktionen, og kan derfor kun tilgås inde i denne funktion. Hvis man prøvede at skrive console.log(notes) uden for funktionen, ville man få en reference error, fordi den ikke er defineret i det globale scope. Hvis man vil have resultatet af funktionen, kan man kalde den med følgende: 

console.log(convertNoteToHZ("A4")) // output: 440

Block scope

Block scope ligner lidt det samme som function scope, men de er ikke helt ens, og det kan godt virke forvirrende at kende forskel på de to, men jeg har lavet denne nedenstående funktion for at forklare forskellen: 

function blockScopeVSFunctionScope() {
            const functionScope = "denne kan tilgås i hele funktionen inklusiv i if statementet"

            if (true) {
                const blockScope = "denne kan kun tilgås i if blokken"
            }

            console.log(functionScope) // denne virker fordi den har function scope
            console.log(blockScope) // denne virker ikke, fordi den kun kan tilgåes i if statementet.
        }

Loops og metoder

Loops bliver brugt til at gennemgå elemeter i et array, hvor man blandt andet kan arbejde med forskellige metoder. Dem vi har gennemgået i undervisningen er map, filter, find og reduce. Det er vigtigt, at man så vidt muligt undgår side effects, som betyder, at man undgår at ændre det oprindelige array, man looper over. I stedet for, kan man returnere et nyt array med de ændringer, man vil have.

Map

Map metoden gennemgår alle elemter i et bestemt array og laver en ændring, hvor den returnerer et helt nyt array. Eksempel med instruments fra array afsnittet: 

const instruments = [
            {id: 1, instrument: "guitar", type: "acoustic"},
            {id: 2, instrument: "guitar", type: "electric"}
            ]

const instrumentTypes = instruments.map((instrument) => {
    return instrument.type
})

console.log(instrumentTypes) // output: ["acoustic", "electric"]

I ovenstående eksempel gennemgår map hvert objekt i arrayet og henter typen fra objektet, og returnerer et nyt array med resultatet. Det vil sige, at det oprindelige array ikke bliver ændret, og vi undgår side effects

Filter

Filter bruges til (som navnet beskriver), at filtrere et array ud fra en bestemt betingelse. Ligesom map, så returnerer filter et nyt array med de elementer, hvor betingelsen er lig med true. Eksempel med instruments arrayet: 

const electricInstruments = instrument.filter((instrument) => {
            return instrument.type === "electric"}
        )

Her bliver arrayet gennemgået med betingelsen om, at typen skal være "electric". Ellers bliver elementet ikke returneret i det nye array, som filter metoden returnerer. På samme måde som map, så ændrer filter i dette eksempel ikke i det oprindelige array, og vi undgår side effects.

Find

I modsætning til filter og map, så returnerer find ikke et nyt array. I stedet for, får man det første element i et array, som opfylder betingelsen. Eksempel er: 

Const getGuitar = instruments.find((instrument) => {
            return instrument.instrument === "guitar"    
        })

I ovenstående eksempel, gennemgår find metoden instruments arrayet, indtil den finder det første element, der opfylder betingelsen og returnerer resultatet. Hvis ikke den finder noget, får man undefined.

FindIndex

Hvis man vil finde et specifik index i et array, kan man bruge FindIndex metoden til at finde et elements placering ud fra en betingelse. FindIndex stopper med at iterere over arrayet, når det finder det første element, der opfylder betingelsen. Ligesom i Find metoden. Eksempel på FindIndex: 

const electricGuitarIndex = instruments.findIndex((instrument) => {
            return instrument.type === "electric"    
        })

Her ville der blive returneret 1, da "electric" ligger på index 1. Hvis ingen af elementerne opfylder betingelsen, vil der blive returneret -1.

Reduce

Reduce kan bruges til at lægge alle tal sammen i et array. Eksempel: 

const numbers = [10, 20, 30]
            const totalNumber = numbers.reduce((runningTotal, number) => {
                return runningTotal + number
            }, 0)

Her gennemgår reduce arrayet og holder styr på værdien i runningTotal (som starter på 0, hvilket er angivet efter callback funktionen). Reduce tager altså imod to argumenter: en callback funktion og en startværdi. Første gang reduce itererer over arrayet, bliver 0 og 10 lagt sammen, og derefter bliver 10 og 20 lagt sammen osv.

ForEach loop

Et forEach loop metoden kan godt sammenlignes med et almindeligt for loop, fordi den også gennemgår elementerne i arrayet en efter en. Forskellen er, at i for loopet kan man selv styre start, slut og tælleren. Med forEach bliver alle elementer i arrayet gennemgået en gang. I undervisningen har vi lært at bruge map, hvis vi skal bruge dataen bagefter, og forEach hvis vi fx skal logge hvert element i konsollen. man kan også bruge forEach til fx. at rendere en liste i HTML for hvert element i arrayet. Eksempel med at logge til konsollen: 

const instruments = ["guitar", "piano"]
            instruments.forEach((instrumet) => {
                console.log(instrument)
            }) // output: "guitar" "piano"

Her bliver der altså skrevet til konsollen for hvert element i arrayet.

Side effects / mutation

En side effect betyder, at elementerne i et oprindeligt array bliver ændret. Det forsøger man så vidt muligt at undgå, så det oprindelige array stadig kan bruges bagefter, uden at den er blevet ændret. Følgende er et eksempel på side effect:. 

const numbers = [1,2,3,4]
            for (let i = 0; i < numbers.length; i++) {
                numbers[i] = numbers[i] + 1
            }
        console.log(numbers) // output: [2,3,4,5]

Her bliver hvert element i numbers arrayet ændret og efter loopet er kørt færdigt, er det oprindelige array ikke længere 1,2,3,4. Man undgår denne mutation / side effect ved at bruge map metoden, som laver et nyt array og gør det oprindelige array uændret.

Type coercion

Type coercion betyder at Javascript automatisk omdanner en værdi fra en datatype til en anden. Fx: 

const price = "10" 
 console.log(`${price}`+ 5) // output "105"

I ovenstående eksempel bliver 5 automatisk konverteret til en string af Javascript. Det vil sige, at værdierne bliver sat sammen som tekst i stedet for at blive lagt sammen, som måske kunne være hensigten. Derfor skal man være opmærksom på, hvilken datatype, man arbejder med. Hvis man gerne vil kunne lave matematiske beregninger, skal datatypen være number, hvilket man kan bruge Number metoden til som eksemplet her:

const priceAsNumber = Number(price) 
 console.log(priceAsNumber + 5) // output: 15

Srict equality

Når man sammenligner to værdier, kan man enten bruge ==, ===, != eller !==.

==
denne sammenligner værdierne og javascript konverterer automatisk datatyperne, ligesom vi så i forrige eksempel med price
===
denne operator sammenligner både værdi og datatypen, og begge skal være ens, før den er true.
!=
Denne bruges til at finde ud af, om to værdier ikke er ens. Denne fungerer på samme måde som ==, hvor værdierne bliver automatisk konverteret af javascript.
!==
Denne har samme princip som ===, hvor den både sammenligner værdi og datatype, og finder ud af, om to værdier ikke er ens. Her bliver der ikke automatisk konverteret af javascript.

For at konkludere, kan man som tommelfinger regel altid vælge at bruge === og !==, så der ikke automatisk bliver konverteret datatyper. Det er også med til at formindske bugs i koden.

Clean code

Clean code er vigtigt, da det handler om at skrive kode, der gør det nemt for sig selv (og for andre udviklere) at læse og forstå koden. Det betyder bl.a, at man skal sørge for at bruge nogle gode og beskrivende navne til sine variabler og funktioner. Derudover skal man forsøge at dele koden op i mindre funktioner og undgå at gentage sig selv for meget og genbruge kode, hvor man kan.

Navne til variabler og funktioner

Som nævnt skal variabler og funktioner have navne, som forklarer tydeligt, hvad de gør eller indeholder. Eksempel:

const x = 100

Koden ovenfor er svær at gennemskue, hvad den indeholder, da navnet ikke siger noget om, hvad den indeholder. Man kunne i stedet for gøre sådan her:

const price = 100

I det her simplificeret eksempel, kan man hurtigt se hvad variablen indeholder.

Funktioner skal være opdelte og have et ansvar

Hvis en funktion kun har en enkelt opgave at tage sig af, er det nemmere at forstå og genbruge. fx:

const addNumbers = (a,b) => {
            return a + b
        }

Her står funktionen for et ansvar og navnet fortæller hvad den gør.

Strict mode

Man kan godt sammenligne strict mode lidt med en linter. De er begge to med til at understøtte clean code, da de for eksempel giver fejl, hvis man prøver at oprettet en variabel som dette: 

number = 10

Hvis man bruger strict mode, vil dette give fejl, fordi man ikke har oprettet variablen med const eller let.

Man slår strict mode til ved at skrive "use strict" i sin fil. I ES modules er strict mode slået til automatisk, men i commonJS er det ikke slået til.
