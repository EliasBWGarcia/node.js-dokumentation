Client Server Model

Nedenstående billeder beskriver kommunikationen mellem clienten og serveren. Clienten er browseren, som sender et request til serveren, når en bruger tilgår en url.

Serveren modtager et request fra clienten og sender et response tilbage. Det kan fx være en ny html side eller noget data i json format.

Hvad er Express?

Express er et framework til Node.js. Det gør det muligt at arbejde med backend i JavaScript som ellers er et frontend sprog. Man kan oprette en servere og håndtere requests fra clienter. Express kommer med nogle funktioner som fx app.get() og er noget der bliver gennemgået nærmere senere i dokumentationen.

Express installeres som nævnt tidligere ved følgende kommando i terminalen:

npm install express

Hvordan opretter man en server med Express?

Som det første, skal man importere Express. Man kan faktisk oprette en server på meget få linjer kode. Sådan her kan det se ud, hvis man bruger ESmodules:

import express from "express"
        const app = express()
        const port = 8080

        app.listen(PORT, () => {
            console.log("appen kører på port", PORT)
        })

App er Express serveren, og det er vigtigt at man også har en port, som serveren kan lytte på. Det sker gennem app.listen(), hvor man så kan tilgå localhost:8080 i dette eksempel

Routes og App.get()

Når clienten besøger en url, bestemmer routen hvad serveren skal returnere i response. Man bruger app.get() for at oprette en route, og så kan man håndtere GET requests.

Et eksempel på en route:

app.get("/", (req, res) => {
        res.send("eksempel")    
        })

Når clienten besøger / (som ofte er forsiden på en hjemmeside), så sender serveren teksten "eksempel" som response. Man kan også returnere andet end tekst. Det kan for eksempel være HTML eller data i JSON format.

Et eksempel på når en route sender data i JSON format:

app.get("/instruments", (req,res) => {
        res.send({data: "guitar"})    
        })

Hvad består en url af og hvad bruges den til?

En URL bruges til at sende en request til en server.

http://localhost:8080/beers/ipa/1

Hvis vi tager udgangspunkt i ovenstående url, kan man dele den op i disse følgende dele:

http
Dette er protokollen
localhost
Dette er domænet, og i det her tilfælde er det localhost, som betyder at serveren kører på sin egen computer.
8080
Dette er porten, som serveren skal lytte på i app.listen()
/beers/ipa/1
Dette er en path, og ipa og 1 er værdier, som jeg forklarer nærmere om på nedenstående afsnit

Path parameters

Dette er værdier, som er en del af pathen som nævnt. I koden markeres disse med et kolen som her: 

app.get("/beers/:beerType/:amount", (req, res) => {
        res.send(req.params)    
        })

Hvis clienten sætter /beers/ipa/1 ind i urlen, vil req.params indeholde beerType med værdien "ipa" og amount med 1"".

Query parameters

Forskellen på path parameters og query parameters er ikke stor. De gør det samme, men det er to forskellige måder at skrive dem på. Forskellen ligger også i, hvordan værdierne står i url'en og hvordan man henter dem i koden. Et eksempel på en url fra undervisningen: 

/bars/forgottenItems?wallet=200&keys=my-house

Her står værdierne efter ?, og de kan hentes med:

req.query
