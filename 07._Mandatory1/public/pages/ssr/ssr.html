Hvad er ssr?

ssr står for Server Side Rendering. Det betyder, at serveren konstruerer HTML siden, før jeg bliver sendt afsted til browseren.

I dette projekt bruger vi serveren til at hente headeren, footeren og selve inholdet fra den side, clienten klikker på. Derefter samler serveren det til en html side og sender det som et response.

I dette projekt, bruger bruger jeg fs til at læse html filerne. 

import fs from "fs"
    export function readPage(path) {
        return fs.readFileSync(path, "utf-8")
    }

readPage() læser html filen og returnere det som en string. Følgende kode viser, hvordan det sættes sammen:

export function constructPage(page, options = {}) {
    const header = readPage("public/components/header/header.html");
    const footer = readPage("public/components/footer/footer.html");

    return header.replace("titel-placeholder", options.title) + page + footer;
}

constructPage bruges til sætte det hele sammen, hvor den færdige html side gemmes og kaldes i denne funktion blandt andre, så de kan bruges i app.js: 

export const javascriptPage = constructPage(javascript, {
    title: "JavaScript og Clean Code"})

app.js sender siden sådan her:

import javascriptPage from "./templatingEngine/pages.js"
            app.get("/javascript", (req,res) => {
        res.send(javascriptPage)    
        })

SSR VS Client Side Rendering

Jeg har lavet denne tabel for at give et overblik over forskellen mellem SSR og Client side rendering:
SSR CSR
Hvordan de konstruere siden Browseren modtager færdig HTML fra serveren. Browseren skal først hente og køre JavaScript
Ressourcer Serveren bruger ressourcer på at lave HTML for hvert request. Browseren bruger ressourcer på at lave indholdet.
SEO Indholdet er nemmere at søge op, da keywordsne allerede findes i HTML svaret på google Indholdet kan først komme frem, når JavaScript er kørt.

CDN VS lokale filer

CDN står for content delivery network. Det betyder, at filer som css kan hentes fra en ekstern server i stedet for at ligge lokalt.

Jeg har fx brugt følgende css styling framewrok til dette projekt:

link rel="stylesheet" href="https://cdn.simplecss.org/simple.min.css"

En fordel ved at hente det fra en ekstern server, er at man ikke selv skal downloade css filen og gemme den i projektet. Det er nemt at starte med, hvis man bare skal lave en simpel hjemmeside som denne.

Til gengæld er man lidt mere i kontrol over filen, hvis man altså vælger at downloade den og lægge den lokalt i projektet. Derudover er hjemmesiden ikke afhængig af en ekstern server.
