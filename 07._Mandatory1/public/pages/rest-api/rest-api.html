Hvad er et REST API?

Man gør det muligt for clienten at bruge http til at arbejde med data. I undervisningen har vi bl.a. lavet et API med animals, hvor man kan hente, oprette, opdatere og slette dyr.

Et REST API består af endpoints (url'er).

Konventioner

I undervisningen har vi arbejdet med konventioner af REST API'er, så det er nemt for andre (og en selv) at læse og forstå koden.

  1. Endpoints skal stå i en specifik rækkefølge, når man skriver koden. Rækkefølgen er følgende: GET, POST, PUT, PATCH og DELETE
  2. Endpoints skal navngives med navneord i flertal.

CRUD og http metoder

CRUD er en forkortelse for alle de handlinger man kan lave i et REST API. Her har jeg lavet en tabel for at få et overblik:

CRUD HTTP metode Eksempel
Create POST POST /animals
Read GET GET /animals
Update PATCH PATCH /animals/:id
Delete DELETE DELETE /animals/:id

GET (read)

GET bruges til at hente data. Her er der et eksempel: 

app.get("/animals", (req, res) => {
        res.send({data: animals})    
        })

Hvis man gerne vil hente et bestemt dyr, i stedet for bare at modtage alt dataen, så kan man gøre sådan her:

app.get("/animals/:id", (req, res) => {
    const providedId = Number(req.params.id)

    const foundAnimal = animals.find((animal) => {
        return animal.id === providedId
    })
})
    res.send({ data: foundAnimal });

Her i ovenstående eksempel fra undervisningen, er ID et path parameter. ID'et kommer som string, så derfor bruger man Number() til at konverte værdien til et tal. Herefter bruges find() til at finde det dyr i arrayet. der har id'et 1.

POST (create)

Man kan oprette ny data på serveren med et POST request. Men det skal være i JSON format i bodyen, og det kan man sørge for at gøre, ved at skrive følgende linje kode før man skal sit REST API: 

app.use(express.json())
app.post("/animals", (req, res) => {
    const providedAnimal = req.body;

    providedAnimal.id = nextId++;

    animals.push(providedAnimal);

    res.send({ data: providedAnimal });
});

Clienten sender et post request til serveren, og opdaterer arrayet med et nyt dyr.

Patch (Update)

I et patch request opdaterer man data på serveren. Eksempel fra undervisningen, hvor vi opdaterer et dyr på en specifik placering (vha id) på animals arrayet:

app.patch("/animals/:id", (req, res) => {
    const providedId = Number(req.params.id);
    const foundAnimalIndex = animals.findIndex((animal) => animal.id === providedId);

    if (foundAnimalIndex === -1) {
       return res.status(404).send({ errorMessage: `No animal found by id ${providedId}` });
    }

    const providedAnimal = req.body;
    const foundAnimal = animals[foundAnimalIndex];

    const animalToUpdate = { ...foundAnimal, ...providedAnimal, id: providedId };

    animals[foundAnimalIndex] = animalToUpdate;

    res.send({ data: animalToUpdate });
});

Delete

Et delete request sletter data på serveren. Eksempel fra undervisningen, hvor id'et bliver brugt til at finde et dyr at slette:

app.delete("/animals/:id", (req, res) => {
    const providedId = Number(req.params.id);
    const foundAnimalIndex = animals.findIndex((animal) => animal.id === providedId);

    if (foundAnimalIndex === -1) {
       return res.status(404).send({ errorMessage: `No animal found by id ${providedId}` });
    }

    animals.splice(foundAnimalIndex, 1);

    res.status(204).send();
});

Statuskoder

Serveren sender et response tilbage med en statuskode. Kort overblik over nogle af de vigtigte:

200
Requestet virkede
204
Requestet virkede, men der bliver ikke sendt noget tilbage fra serveren
404
Serveren kunne ikke finde det, der blev requestet om (ses også i delete eksemplet ovenfor)
