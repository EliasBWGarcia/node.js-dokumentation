Hvad er Node.js?

Med Node.js kan man køre JavaScript uden for browseren, hvor Javascript normalt kører og gør en hjemmeside interaktiv. Med Node.js kan man køre Javascript fra terminalen og bruge det til at lave server kode. I undervisningen har vi brugt Node.js til at køre Express servere (læs mere om Express på knappen i navigationsmenuen).

Hvordan kører man en js fil?

I terminalen kører man:

node navnPåFil.js

Hvad er NPM?

NPM er en package manager og står for Node Package Manager. Det bruges bl.a. til at installere pakker i et projekt.

En pakke er noget kode, som andre har lavet, og som man kan tage i brug i sit eget projekt. I undervisningen har vi brugt Express pakken til at oprette vores servere. 

npm install express

Hvis man kører ovenstående kommando i sin terminal, installerer vores package manager pakken Express. Der bliver også opdateret i package.json, package-lock.json og mappen node_modules.

npm-init og package.json

Package.json er en fil, der fortæller hvilken version projektet er på, og hvilke dependencies/pakker projektet bruger. Når man installerer en pakke med npm install i terminalen, så bliver pakken automatisk tilføjet under dependencies i package.json. Man kan oprette denne fil ved at skrive følgende i terminalen: 

npm init

Her bliver der stillet nogle spørgsmål om projektet, hvor svarene automatisk kommer ind i package.json. Man kan dog også skrive oplysningerne ind i filen selv. Sådan kan en package.json fil se ud:

{"name": "mandatory-1-documentation",
  "version": "1.0.0",
  "private": true,
  "type": "module",
  "scripts": {
    "start": "node app.js",
    "start-dev": "nodemon app.js"
  },
  "dependencies": {
    "express": "^5.2.1"
  },
  "devDependencies": {
    "nodemon": "^3.1.10"}
    }

Der sker også mere, når man kører npm install i terminalen, og det bliver nævnt i næste underemne.

Node_modules, package-lock.json & gitignore

Når man skriver npm install i terminalen, bliver der oprettet en mappe, der hedder node_modules. Den indeholder alle de pakker, projektet bruger. Mappen kan blive rigtig stor, og derfor pusher man det ikke til Github og node_modules bliver lagt i gitignore. Alle de oplysningerne står allerede i package.json og package-lock.json (fil som fortæller hvilke versioner pakkerne har), så en anden udvikler kan bare hente projektet ned og køre npm install i terminalen og installere dependencies/pakkerne på ny.

Npm scripts og Nodemon

Et npm script står i package.json og en slags genvej til en kommando i terminalen. Man kan også oprette sine egne. Et eksempel på scripts i package.json i dette projekt er følgende:

"scripts": {
    "start": "node app.js",
    "start-dev": "nodemon app.js"
  }

På ovenstående eksempel, kan vi se at der er to scripts i package.json. Hvis vi skriver npm start i terminalen, bliver kommandoen "node app.js" kørt. Man skal dog skrive npm run start-dev for at udføre nodemon scriptet, da dette ikke et særligt keyword i node.js, som npm start er.

Ift. Nodemon bliver det brugt til at udvikle et projekt undervejs. Det er smart, fordi at Nodemon altid genstarter Node.js serveren, når man gemmer en ændring. Så slipper man for at stoppe og starte serveren hver gang, man har lavet en ændring.
